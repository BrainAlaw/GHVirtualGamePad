# Third-party components

This development bundle contains a Rust binary linked with crates listed in Cargo.lock. Their licenses include MIT, Apache-2.0, BSD-2-Clause and related permissive terms; see each crate's package metadata and source license files before public redistribution.

Qt for Python (PySide6/Shiboken6) and Qt are downloaded from PyPI on first launch, not embedded in this test archive. Qt licensing information: https://doc.qt.io/qtforpython-6/licenses.html

The Linux static binary uses musl; license: https://git.musl-libc.org/cgit/musl/tree/COPYRIGHT

Original application code and the program icon are licensed under MIT; see LICENSE. Third-party components retain their own licenses. Public binary release still requires assembling complete dependency notices/source obligations, especially before bundling Qt into an offline installer or AppImage.
